# PathSnap Evaluator UI

The evaluator dashboard is a Streamlit app. It checks backend health, loads trip IDs from `GET /trips`, and submits the selected ID to `POST /predict` as JSON:

```json
{"trip_id": "<selected trip ID>"}
```

## Run locally

From the repository root, install the project dependencies and start the UI:

```bash
python -m pip install -r requirements.txt
streamlit run ui/app.py
```

The default backend URL is `http://127.0.0.1:8000`. To point this laptop at a backend running elsewhere, set `PATHSNAP_API_BASE_URL` before starting Streamlit.

PowerShell:

```powershell
$env:PATHSNAP_API_BASE_URL = "http://<backend-laptop-ip>:8000"
streamlit run ui/app.py
```

Bash:

```bash
export PATHSNAP_API_BASE_URL="http://<backend-laptop-ip>:8000"
streamlit run ui/app.py
```

The current backend files do not yet define or implement these endpoints. The dashboard currently accepts `GET /trips` as either a JSON list of IDs (or objects with `trip_id`) or an object containing a `trips` list in that form. `GET /health` must return valid JSON, and `POST /predict` must accept the JSON request above and return valid JSON. Prediction results are displayed as returned; no output values are generated by the UI.

The map adapter in `map_adapter.py` accepts route points as `(latitude, longitude)` pairs. The prediction response schema does not yet specify where or how those coordinates are returned, so the dashboard does not infer them from the response. Agree on that contract before wiring predictions into the map.
